輕量化的任務清單，支援動態的新增、刪除與勾選標記。

綠界金流串接與 Debug 實作

⚠️ 提示：本專案包含 Node.js 後端伺服器與私鑰環境，無法在 GitHub Pages 靜態網頁直接執行付款。

🛠️ 技術亮點與實作內容

  • 後端環境建置：使用 Node.js / Express 搭建輕量化網頁伺服器。
  • 資安防護隔離：導入 dotenv 套件，將敏感的 HashKey 與 HashIV 抽離至 .env 環境變數中，防止私鑰外洩。
  • 官方 SDK 整合：串接 ecpay_aio_nodejs 套件，自動生成符合規格的 SHA256 加密檢查碼（CheckMacValue）。
  • 自動化除錯練習：成功修正專案中刻意保留的時間戳記與語法錯誤，實現本機環境與綠界測試付款頁面的無縫跳轉。
